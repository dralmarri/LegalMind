# pipeline/ — خطُّ بناء قاعدة المعرفة القانونية

هذا المجلَّد نسخةٌ احتياطيةٌ من أدوات بناء قاعدة المعرفة التي كانت — قبل هذا الإيداع — تعيش
في مساحةِ عملٍ مؤقّتةٍ تزول بزوال الجلسة. وهي المسارُ الذي دخل به كلُّ قانونٍ في القاعدة، فبها
وحدَها يُعاد بناءُ ما فيها إن ضاع.

## الترتيب

| المجلَّد | ما فيه |
|---|---|
| `sources/` | **النقولُ الخام**: نصوصُ القوانين منقولةً بصريًّا من صور الجريدة الرسمية وملفّات PDF، وملفّاتُ التعديلات، وسجلّاتُ الاختلافات بين النسخ. أغلى ما هنا جهدًا، وأصعبُه تعويضًا. |
| `make_*.py` (في `make/`) | **المُحوِّلات**: تقرأ النقلَ الخام وتُخرج JSON مفكَّكًا مادّةً مادّةً، مع الأبواب والفصول وحالةِ التعديل. |
| `parsed/` | مُخرَجاتُ المُحوِّلات — JSON جاهزٌ للإدخال. |
| `ingest/` | **المُدخِلات**: تحوّل JSON إلى كائنات `knowledge_objects` في PostgreSQL، بفرعٍ وموضوعٍ وميتاداتا. |
| `build/` | **بُناةُ النشرات**: تُغلّف المُدخِلَ أو `admin/app.py` في سطرٍ واحدٍ ذاتيِّ التنفيذ (gzip+base64) يُلصَق على الخادم — طريقةٌ تُغني عن SFTP. |
| `tools/` | أدواتُ فحصٍ ومعاينةٍ ومقابلة: مسبارات قاعدةٍ للقراءة فقط، ومُصحِّحاتٌ نصّيةٌ مستهدَفة، وفاحصاتُ ترتيبٍ محلّية. |

## الدورةُ كاملةً

```
صورةُ الجريدة  ⇒  sources/*.txt   (نقلٌ بصريّ، ⟦صN⟧ لكلّ صفحة)
                ⇒  make/make_*.py  ⇒  parsed/*.json
                ⇒  ingest/ingest_*.py            ⇒  PostgreSQL
                ⇒  engine reindex                ⇒  Qdrant
                ⇒  admin/app.py (محفّزاتُ الاستحضار)
```

## قواعدُ لا تُخرَق

1. **النصُّ المشكوكُ فيه يُرفَض، ولا يُخمَّن.** إن كان النقلُ تالفًا طُلبت صورةٌ نظيفة.
2. **التصحيحُ مستهدَفٌ ومُسنَد.** لا يُصحَّح إلّا ما هو لا-كلمةٌ في العربية أو ما حسمه استدراكٌ
   رسميّ، ويُدوَّن سندُه في `sources/*_divergences.md`.
3. **لا يُدمَج التعديلُ الجزئيّ في المتن دمجًا تقديريًّا** — الدمجُ تأليفٌ لا نقل. يبقى متنُ
   الأصل ويُلحَق به الشقُّ المعدَّل موسومًا، ويُحفَظ المستبدَلُ في `metadata`.
4. **الفحصُ على الترتيب لا على الوجود.** حِزمُ الاستحضار تُقاس بموضع المعرّف في النافذة
   (`index < 18`) لا بمجرّد ظهوره — فالظهورُ خارج النافذة كالغياب.

## الأسرار

سلاسلُ الاتّصال هنا تحمل العلامةَ `__SET_DATABASE_URL_ENV__` مكانَ كلمة المرور — نُزعت عمدًا
قبل الإيداع. والسكربتاتُ كلُّها تقرأ `DATABASE_URL` من البيئة أوّلًا، فالتشغيلُ الصحيح:

```bash
set -a; . /opt/LegalMind/deploy/.env; set +a
python3 pipeline/ingest/ingest_<law>.py pipeline/parsed/<law>_parsed.json --dry-run
```

## ما ليس هنا

- **صورُ الصفحات وملفّاتُ PDF** — حجمُها مئاتُ الميغابايت، ومصدرُها الجريدةُ الرسمية.
- **ملفّاتُ `DEPLOY_*.txt` و`run_*.sh`** — مولَّدةٌ آليًّا من `build/`، تُعاد متى شئت.
- **قاعدةُ البيانات نفسُها** — بياناتٌ لا شيفرة؛ حمايتُها بالنسخ الاحتياطي على الخادم
  (`deploy/backup.sh` و`deploy/install_backup_timer.sh`).
