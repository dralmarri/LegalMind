# استخراج القوانين الغائبة من «مجموعة التشريعات» (التعديلات حتى 2026/10/5)

أدوات الجولة الموثقة في CLAUDE.md §20 — للتدقيق وإعادة الإنتاج، لا تعمل على الخادم.

1. `pages.pkl` = صفحات ملف Markdown المرجع مقسومة على `## صفحة PDF N` (يُبنى من الملف المرفوع).
2. `python3 extract.py DIR` ← `DIR/extracted.json` (التنقية الآلية المعدودة + المواد + الحواشي + الفهرس).
3. `python3 build.py DIR` ← `DIR/records.json` (السجلات بميتاداتها ووسوم الاضطراب).
4. السجلات تُضمَّن مضغوطة في `tools/ingest_reference_missing_20261005.py`.
